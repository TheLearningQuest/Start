# Coloring pictures

These are original coloring-book drawings made for Cole's Quest. A matching public-domain set in one style was not available, so each picture was drawn for this app and dedicated to the public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

There is no upstream file. The page loads every picture from `cole/assets/coloring/`.
